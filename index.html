  2. Track 02

    2026 · Team of 4 · Edge AI

    Single-Frame Face Liveness Detection on Edge Hardware

    Spoiler: a photo of you is not you. An anti-spoofing system that decides from a single camera frame whether a face is a real person or a presentation attack such as a printed photo or a screen replay. It combines MediaPipe face landmarks, two MiniFASNet models run through ONNX Runtime, and an FFT-based moire score for screens, and it is built for a Raspberry Pi with a live Flask dashboard.

    • 3.4% ACEROULU-NPU Protocol 1
    • 16.2 ms / framelaptop CPU
    • 24.5% / 27.2% HTERcross-dataset (CASIA-FASD and Replay-Attack, both directions)
    Liner notes
    • Built a single-frame presentation attack detection pipeline for low-power edge hardware, fusing MiniFASNet predictions, head-turn (yaw) from 478 face landmarks, and a screen-texture moire score, with a rolling 20-frame window for stable verdicts.
    • My contribution: loaded and integrated the models on the Raspberry Pi pipeline, ran the system end to end, and tested it.
    • Evaluated with APCER, BPCER and ACER, and documented the approach in an IEEE-style report.
    • Python
    • OpenCV
    • MediaPipe
    • ONNX Runtime
    • NumPy
    • Flask
    • Raspberry Pi
    Private repository, team project
  3. Track 03

    2026 · Team project · Live

    Reddit r/technology Sentiment and Virality Analyzer

    What makes a tech post blow up? Turns out being grumpy helps a lot.

    • 0.7833 test ROC AUC
    • 2,091 posts
    • 27.4% vs 16.8% viral, negative vs positive
    Liner notes
    • Worked with a 2,091-post dataset from r/technology.
    • Stacked RoBERTa sentiment, TF-IDF, a 15-topic LDA model and spaCy NER into one feature set.
    • Kept every feature leakage-free, so the score reflects real predictive signal.
    • Logistic Regression reached 0.7833 ROC AUC on the held-out test set.
    • Headline finding: negative posts go viral at nearly 2x the rate of positive ones (27.4% vs 16.8%).
    • Shipped as a live Streamlit dashboard anyone can poke at.
    • Python
    • HuggingFace Transformers
    • spaCy
    • Scikit-learn
    • Streamlit
